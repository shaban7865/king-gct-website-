MUHAMMAD SHABAN — GCT KAMALIA PRACTICE WEBSITE

HOW TO RUN
1. Extract this ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. Right-click and choose "Open with Live Server" (if installed), or double-click index.html.

FILES
- index.html: website content
- style.css: layout, colors, and responsive design
- script.js: mobile navigation menu
- assets/muhammad-shaban.jpg: your profile photo

IMAGES
College department and lab images are linked from the public GCT Kamalia website, so an internet connection is required for those images to load.
Official source: https://gctkamalia.edu.pk/

IMPORTANT
This is a student practice website and is not the official college website. College details can change; confirm official information with the college.
